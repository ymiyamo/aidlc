# モックアップ（画面設計）

ユーザーストーリー（`stories.md`）と要件（`requirements.md`）をもとにした、スマートフォン向け（幅 360px 以上、縦向き）の画面設計です。質問への回答（`refined-mockups-questions.md`）を反映しています。見た目の確認には、`html/index.html` の HTML モックを使えます（動作はしません）。

ラフなモックアップ（`wireframes.md`、`user-flow.md`）は、このスコープでは作っていないため、ここから直接設計しています。

## 設計の方針

- **中心は「買い物前」の画面**。アプリを開いたら最初にこの画面を見せる [Q2 A]。
- **候補は 1 件ずつ、大きなカードで見せ、左右のスワイプで「これにする」「パス」を選ぶ** [R1 B]。YouTube Shorts や Instagram のように、次々に見ていける感覚を目指す。スワイプができなくても、ボタンで同じ操作ができる（NFR1.5）。
- **料理のイメージ画像を見せる** [R9 X]。利用者が登録した画像があればそれを、なければ生成 AI で作った画像を表示する。AI の画像には「AI が作ったイメージ」の印を付ける。
- 絞り込みは、横スクロールのチップをやめ、**「今日の気分」を選ぶパネル**（大きなタイルが折り返して並ぶ）にする [R2 X]。
- 保存は、**どの画面からでも右下の「＋」**で開ける [R4 A]。
- 移動は画面の下の 4 つのタブ。ほかは右上のメニュー [Q1 A]。
- 叱らない・急かさない言葉づかいにする [Q8 A]。

## 共通の枠組み

```
┌─────────────────────────────┐  幅 360px 以上
│ 画面の名前              ⋮    │  ← 上部バー（⋮：好き嫌い／グループ／アカウント）
├─────────────────────────────┤
│                             │
│        （画面の内容）         │
│                       [＋]  │  ← 右下の「＋」：どの画面からでも保存を開く
├─────────────────────────────┤
│ 🍽買い物前│📌保存 │ 📅献立 │ 📝記録 │  ← 下部タブ（高さ 56px）
└─────────────────────────────┘
```

- 下部タブは 4 つ：「買い物前」「保存」「献立」「記録」。「保存」タブは、保存した項目の一覧（S5）を開く。
- 保存の入口は 3 つ：右下の「＋」（S4 を開く）、買い物前の「貼り付けて保存」、共有メニュー（使える環境のみ。OQ2）[R4 A]。
- 買い物リスト（S7）への入口は、「買い物前」の右上の 🛒 と、画面下の「選んだもの N 件　買い物リストを見る」。名前は「買い物リスト」にそろえる。

## S3 買い物前（ホーム）

```
┌─────────────────────────────┐
│ 買い物前                🛒 ⋮│
├─────────────────────────────┤
│ [今日の気分：15分以内・楽 ▾] [おまかせ]│
│        3 / 12 件目           │
│ ┌─────────────────────────┐ │
│ │  ┌───────────────────┐  │ │
│ │  │   （料理の画像）     │  │ │  ← 利用者の画像、なければ AI の画像
│ │  │ [AIが作ったイメージ]  │  │ │
│ │  │ 鮭のホイル焼き        │  │ │
│ │  └───────────────────┘  │ │
│ │ 15分・楽・さっぱり      ♡ │ │
│ │ [元の投稿を見る ↗ ／くわしく]│ │
│ └─────────────────────────┘ │
│  ← パス          これにする → │  ← 左右にスワイプ
│  [ ✕ パス ]    [ ♥ これにする ]│  ← ボタンでも同じ操作ができる
│ [貼り付けて保存]  [外で探す ↗]  │
│ [選んだもの 1 件 買い物リストを見る]│
├─────────────────────────────┤
│ 🍽買い物前│📌保存 │ 📅献立 │ 📝記録 │
└─────────────────────────────┘
```

- 候補は 1 件ずつ。右にスワイプするか「これにする」で、その項目が「選んだもの」に入り、材料が買い物リストに追加される [R5 B]。日付は付けない。
- 左にスワイプするか「パス」で、次の候補へ。パスした項目は、候補をリセットするまで出さない。
- 「今日の気分」を押すと、絞り込みのパネル（S3c）が出る。
- 「おまかせ」は、絞り込みなしで 1 件をランダムに出す [R8 A]。
- 「外で探す」は、今の気分・調理時間のキーワードを入れて、YouTube／Instagram の検索画面を開く [R8 A]。結果は取り込まない。
- 「貼り付けて保存」は、クリップボードの URL が入った保存の画面を開く。
- 「選んだもの」は、献立の画面（S8）で、日に割り当てる候補として使える（US5.6）。
- 材料が未入力の項目には、「材料が未入力」の小さなラベルを付ける。初期データの項目には「サンプルの料理」の印を付け、元の投稿のボタンを無効にする。

状態は S3b を参照（保存 0 件、絞り込み 0 件、見終えた、エラー）。

## S3c 今日の気分（絞り込みのパネル）

```
┌─────────────────────────────┐
│ ✕      今日の気分は？  [クリア] │
├─────────────────────────────┤
│ どのくらい時間をかけられる？    │
│ [⚡15分以内][⏱30分以内][🍳じっくり]│
│ どのくらい頑張れる？           │
│ [😪楽したい][🙂ふつう][💪頑張れる]│
│ 食べたい気分は？              │
│ [さっぱり][がっつり]           │
│ [あたたかい][野菜たっぷり]      │
│ [ごはんが進む][＋気分を足す]    │
├─────────────────────────────┤
│ 8 件が見つかりました           │
│ [      8 件を見る      ]      │
│ [この気分で外で探す ↗]         │
└─────────────────────────────┘
```

- 横にスクロールしない。タイルは折り返して並び、1 つが 64px 以上の高さ。
- 選ぶたびに、該当する件数が変わる。何も選ばなければ、すべてから出す。
- 気分のタグは、利用者が付けたものが並ぶ。「＋ 気分を足す」で自分の言葉を足せる。

## S4 保存する

```
┌─────────────────────────────┐
│ ←  保存する                 │
├─────────────────────────────┤
│ 投稿の URL（必須）           │
│ [https://___________]       │
│ 料理名（必須）               │
│ [__________________]        │
│ ▼ くわしく入力する（任意）    │
│   調理時間／手間／気分のタグ／ │
│   材料と分量／食材の種類／メモ  │
│   画像を登録する（任意）       │
│ [          保存          ]   │
└─────────────────────────────┘
```

- 必須は URL と料理名だけ [R3 B]。詳しい情報は閉じておき、あとからでも足せる。
- 「画像を登録する」は任意。登録しなければ、AI の画像が表示される [R9 X]。

## S5 保存した項目の一覧

- 各行に、小さな画像、料理名、条件、お気に入りの印を表示する。初期データには「サンプルの料理」の印を付ける。
- 「すべて」「お気に入り」の切り替え。右下の「＋」で保存。

## S6 項目の詳細

```
┌─────────────────────────────┐
│ ←  鮭のホイル焼き        ♡   │
├─────────────────────────────┤
│ （画像／AI が作ったイメージ）   │
│ [元の投稿を見る ↗]            │
│ 15分・楽・さっぱり／材料／メモ  │
│ ── 作った日（3 回）──         │  ← 項目と作った日は 1 対多
│  10/09  ♥ また作りたい         │
│         メモ：弱火で…          │
│  09/20  ✕ もう作りたくない     │
│  09/02  （感想なし）           │
│ [ ＋ 作った日を追加 ]          │
└─────────────────────────────┘
```

- 大きな画像（AI の画像には印）、元の投稿へのリンク、「画像を登録する」、条件・材料・メモ。
- **「作った日」の一覧**：その項目を作った日が、日付の新しい順に並ぶ（作った回数、各回の感想、注意点メモ）。項目と作った日は 1 対多で、何回でも追加できる [J1]。
- 一覧の行を押すと、その記録の編集・削除ができる（削除は確認のあと）。
- 「作った日を追加」を押すと、パネルが下から出る：作った日（初期値は今日。未来は選べない）、感想（任意：また作りたい／もう作りたくない）、注意点メモ（任意）。同じ日の記録がすでにあるときは、知らせて編集を案内する。

## S7 買い物リスト

- 「これにする」で選んだ項目の材料が自動で入る [R5 B]。選んだものを外すと、その材料も外れる。
- チェックを付けると取り消し線を引き、下へ移す。材料が未入力の項目は「材料の入力が必要」と表示する。

## S8 1 週間の献立

```
┌─────────────────────────────┐
│ 献立             [保存した献立]│
├─────────────────────────────┤
│ [ 1週間の献立を作る ]         │
│ 買い物前で選んだもの（2 件）    │
│ [鮭のホイル焼き][鶏肉のトマト煮] │
│ 月  鮭のホイル焼き   [やり直し] │
│ 火  鶏肉のトマト煮   [やり直し] │
│ 水  作らない（外食）   [解除]   │  ← 「この日は作らない」
│ 木  卵とほうれん草…[やり直し][作らない]│
│ ...                         │
│ [週全体をやり直す]  [保存]     │
└─────────────────────────────┘
```

- 献立の期間は 1 週間のまま [R6 X]。
- 日ごとに「作らない」を設定できる。設定した日は、提案と買い物リストの対象から外れ、「空き」にも数えない。「解除」で元に戻せる [R7 X]。
- 買い物前で選んだものは、日に割り当てる候補として上に表示する（US5.6）。
- 「保存した献立」から、保存した献立の一覧を開き、呼び出して使える。

## S9 記録（カレンダー／一覧）

```
┌─────────────────────────────┐
│ 記録  [カレンダー|一覧]        │
├─────────────────────────────┤
│ ◀   2026 年 10 月   ▶        │
│ 日 月 火 水 木 金 土          │
│  3: ♥ 豚の生姜焼き           │  ← 日をタップしなくても
│  5: ✕ 鶏のトマト煮           │     料理名と印が見える
│  9: ♥ 鮭のホイル焼き ♥ 味噌汁 │
│ ♥：また作りたい  ✕：もう作りたくない│
│ 10 月の記録（一覧）           │  ← カレンダーの下に月の一覧
│  10/09 鮭のホイル焼き ♥ …    │
└─────────────────────────────┘
```

- カレンダーと一覧は切り替えられ、カレンダーの下にもその月の一覧を出す [R10 X]。
- 1 日に複数あるときは、複数あることが分かる表示にする。
- **日付をタップして、作ったものを追加する** [J2]（検討中の操作。下の流れを案とする）：

```
 カレンダー ──日付をタップ──▶ その日の記録（S9a）
   ・その日の記録の一覧（料理・感想・メモ）。0 件でも開く
   ・[ ＋ 作ったものを追加 ]
        │
        ▼
 作ったものを選ぶ（S9b）
   ・料理名の検索
   ・[最近選んだもの｜お気に入り｜すべて]
   ・見つからないとき → 「保存する」の画面へ（OQ11）
        │ 項目をタップ
        ▼
 感想とメモ（S9c）
   ・作った日（タップした日。今日までの日付のみ）
   ・感想（任意）：また作りたい／もう作りたくない
   ・注意点メモ（任意）
   ・[保存]
        │
        ▼
 その日の記録（S9a）に追加された状態に戻る
```

- 記録のない日をタップしても同じ流れで追加できる。未来の日付は、「作ったものを追加」を押せない（理由を表示する）。
- 同じ日に別の項目を続けて追加できる（1 日に複数）。同じ日に同じ項目を追加しようとしたときは、知らせて、既存の記録の編集を案内する。
- その日の記録の一覧から、記録を編集・削除できる。

## 承認のときに確認してほしい点（未解決の点）

要件定義書（`requirements.md`）の未解決の点のうち、この画面設計に関わるものです。

- **OQ8 「この日は作らない」を消す意味**：「設定を解除して、その日をもう一度提案の対象にする」と解釈した。「その日の枠そのものを献立から消す」意味なら、S8 の設計を見直す。
- **OQ7 生成 AI の画像**：使うサービス、作るタイミング（保存した直後か、あらかじめか）、費用と回数の上限、著作権・安全面、作っている間の表示が未決定。画面では、色の枠を出しておき、できたら入れ替える想定。
- **OQ9 YouTube のサムネ画像**：URL から取れることが多いが、今回の回答（登録画像、なければ AI の画像）には含まれていない。使うかどうかが未決定。
- **OQ10 献立の期間**：いったん 1 週間のまま。1〜7 日などへの変更は、使ってから見直す。
- **記録の登録（OQ11、OQ12）**：カレンダーの日付から追加する流れ（S9a〜S9c）は検討中の案。保存した項目にない料理を作ったときの扱い（URL なしでも料理名だけで項目を作れるようにするか）、同じ日に同じ項目を二重に登録できない決まりでよいか、献立（S8）や「選んだもの」から直接「作った」を記録する入口を足すか、を決める。
- **保存の手間の軽減**：「詳しく入力するのが大変」という感想に対し、R3 では今のまま（URL と料理名が必須）にした。手間を減らす工夫は、最初の版を使ってから見直す。
- **スワイプの細部**：確定する距離の値、縦スクロールとの区別、「直前に戻す」の要否は、実装時に決める。

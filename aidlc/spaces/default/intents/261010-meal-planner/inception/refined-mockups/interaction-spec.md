# 操作仕様（インタラクション）

`mockups.md` の各画面について、操作と状態の決まりをまとめます。

## 共通の決まり

- アクセシビリティ（WCAG 2.1 AA）の達成は、ここでの設計だけでは判断できない。実装後に、支援技術を使った手作業の確認と、専門家による確認で判断する（`accessibility-checklist.md`）。

- 押せる部分の大きさは、縦横とも 44px 以上にする。
- 操作の結果はすぐに画面に出す。通信を待つ場合は、ボタンの近くに進行を表示し、二重に押せないようにする。
- 取り消せない操作（削除、グループから抜ける、アカウント削除）は、必ず確認のダイアログを出す。
- エラーは、何が起きたかと次にすることを、短い文で示す。専門用語は使わない。
- 言葉づかいは、叱らない・急かさない（例：「もう一度試す」「あとで入力してもよいです」）。

## 画面ごとの操作

### S3 買い物前

| 操作 | 結果 |
|---|---|
| 画面を開く | 候補を 1 件、大きなカードで表示する（絞り込みなしなら全項目から） |
| 右にスワイプ／「これにする」 | その項目を「選んだもの」に入れ、材料を買い物リストに追加し、次の候補を出す |
| 左にスワイプ／「パス」 | その項目をリセットするまで出さないようにして、次の候補を出す |
| 「今日の気分」を押す | S3c のパネルを開く。選んだ条件で候補を最初から出す |
| 「おまかせ」を押す | 絞り込みなしで、保存した項目（初期データを含む）から 1 件をランダムに出す |
| 「外で探す」を押す | 今の気分・調理時間のキーワード入りで、YouTube／Instagram の検索画面を別の画面で開く。結果は取り込まない |
| 「貼り付けて保存」を押す | クリップボードの URL が入った保存の画面（S4）を開く |
| 最初から見る | パスした履歴を消し、候補を最初から出す |
| 元の投稿を見る | 元のサービスの投稿を、別の画面（または別のタブ）で開く（初期データの項目では無効） |
| ♡ を押す | お気に入りにする／外す |
| 選んだものを外す | 「選んだもの」から外し、その材料を買い物リストから外す |

- スワイプの操作は、すべてボタンでもできる（NFR1.5）。スワイプの途中で指を離したときは、画面幅の 3 割（目安）を超えたら確定し、超えなければカードが元の位置に戻る。縦のスクロールとの区別と、しきい値の最終的な値は、実装時に端末で試して決める。
- 誤ってパスしたときのために、「直前に戻す」ボタン（1 件前の候補に戻る）を置くかどうかは、使ってから決める（未決定）。
- 絞り込みを変えたら、パスの履歴は最初からになる。
- 候補の並び：同じ条件の中では、「もう作りたくない」の項目を最後に並べる。
- 「選んだもの」は、献立（S8）の画面で、日に割り当てる候補として表示する。

### S4 保存する

| 操作 | 結果 |
|---|---|
| URL を入力 | 入力のたびではなく、保存を押したときに形（http または https）を確認する |
| 保存 | 必須の 2 項目が入っていれば保存し、S5 の一覧に戻って「保存しました」を表示する |
| 「くわしく入力する」を開く | 任意の項目を表示する |
| 戻る | 入力中の内容があるときは、「保存せずに戻りますか」と確認する |

### S6 項目の詳細

| 操作 | 結果 |
|---|---|
| 作った感想を記録する | 下からパネルを出す。感想（2 択のどちらか）を選ぶと保存を押せる。注意点メモは空でもよい |
| 保存（感想） | 記録を保存し、パネルを閉じて「記録しました」を表示する。すでに記録があれば置き換える |
| 削除 | 確認のあと、項目を削除する（買い物リストや献立にある場合は、その行を「削除された項目」として表示する） |

### S7 買い物リスト

| 操作 | 結果 |
|---|---|
| 材料を押す | チェックの付け外し。付けたものは取り消し線を引き、下へ移す。状態は保存する |
| 画面を再び開く | 保存したチェックの状態で表示する |

### S8 1 週間の献立

| 操作 | 結果 |
|---|---|
| 1週間の献立を作る | 7 日分の提案を表示する（3 秒以内） |
| 日ごとの 作らない | その日を「作らない」にし、料理を外す。提案・買い物リストの対象から外し、「空き」に数えない |
| 日ごとの 解除 | 「作らない」を消し、その日をふつうの日に戻す（料理は提案させられる） |
| 選んだものを日に割り当てる | 「買い物前で選んだもの」から料理を選び、日を選ぶとその日に入る |
| 日ごとの やり直し | その日だけを別の料理に変える。同じ料理が 1 週間に 2 回までの決まりを保つ |
| 週全体をやり直す | 7 日分を別の組み合わせにする |
| 保存 | 提案を保存する。保存後は「保存した献立」から呼び出せる |

### S3c 今日の気分

| 操作 | 結果 |
|---|---|
| タイルを押す | 選択状態を切り替える（✓ の印を付ける）。選ぶたびに、該当する件数を更新する |
| 「見る」を押す | パネルを閉じ、選んだ条件の候補を最初から出す |
| 「クリア」を押す | すべての選択を外す |
| 「気分を足す」を押す | 自分の言葉の気分のタグを入力して追加する |

### S9 記録

| 操作 | 結果 |
|---|---|
| 「カレンダー」「一覧」を押す | 表示を切り替える |
| ◀ ▶ を押す | 前の月・次の月に移る |
| 日をタップ | その日の記録の一覧（S9a）を開く。記録のない日でも開く。「作ったものを追加」ボタンを表示する（未来の日付では押せず、理由を表示する） |
| 「作ったものを追加」を押す | 作ったものを選ぶ画面（S9b）を開く |
| S9b で料理名を入力・タブを切り替える | 項目を絞り込む（最近選んだもの／お気に入り／すべて） |
| S9b で項目をタップ | 感想とメモの画面（S9c）を開く |
| S9b で「見つからない」を押す | 「保存する」の画面（S4）へ案内する |
| S9c で保存 | 作った日（タップした日）の記録として保存し、S9a に戻る。感想・メモは空でもよい |
| 同じ日に同じ項目を追加 | 「すでに記録があります」と知らせ、既存の記録の編集を案内する |
| 記録の行を押す | その記録の編集・削除（確認のあと）ができる |

### S6 項目の詳細：作った日の記録

| 操作 | 結果 |
|---|---|
| 「作った日を追加」を押す | パネルを開く。作った日（初期値は今日、未来は選べない）、感想（任意）、注意点メモ（任意） |
| パネルで保存 | 項目に、作った日の記録を 1 件追加する（1 つの項目に何件でも追加できる）。「作った日」の一覧に反映する |
| 一覧の行を押す | その記録の編集・削除ができる |
| 詳細を開く | 「作った日」の一覧（日付の新しい順、回数、各回の感想とメモ）を表示する |

- カレンダーの各日には、日をタップしなくても、料理名（短く）と感想の印が見える。カレンダーの下には、その月の記録の一覧を出す。

### S10 好き嫌い

| 操作 | 結果 |
|---|---|
| 追加 | 入力した食材を、自分の「嫌いな食材」に追加する（空欄・重複は追加しない） |

## 画面の幅

- 基本は幅 360px 以上のスマートフォン（縦向き）[Q7 A]。
- 幅がそれより広いとき（パソコンなど）は、内容を中央に寄せ、幅は 480px までに制限して表示する。2 列などの配置は行わない。
- 横にスクロールせずに、主要な操作ができる。

## 部品（コンポーネント）の仕様

技術の選定（次の段階）で決めるため、部品の種類と振る舞いだけを定める [Q6 C]。

| 部品 | 振る舞い |
|---|---|
| 下部タブ | 4 つのタブ。選択中のタブは色と文字で区別する（色だけに頼らない） |
| カード（候補） | 画像、料理名、条件の表示、♡。左右にスワイプでき、「パス」「これにする」のボタンでも同じ操作ができる |
| タイル（今日の気分） | 押すと選択状態が切り替わる。選択中は色・チェック印で示す。折り返して並び、横にスクロールしない |
| チップ | 押すと選択状態が切り替わる。選択中は色・チェック印で示す（S5 などの切り替えで使う） |
| 右下の「＋」ボタン | どの主な画面でも右下に表示し、押すと保存の画面を開く |
| カレンダー | 日ごとに、料理名（短く）と感想の印を表示する。日をタップすると詳細を出す |
| 下からのパネル | 開くと背景を暗くし、ほかの操作を止める。閉じるボタンと、戻る操作で閉じられる |
| 確認ダイアログ | 取り消せない操作の前に出す。「やめる」と「実行する」の 2 択。初期のフォーカスは「やめる」 |
| 通知（トースト） | 数秒で消える。重要なエラーは消えずに残す |
| 画像（サムネ） | 利用者の登録画像、なければ AI の画像。AI の画像には「AI が作ったイメージ」の印を付け、画像の説明（代替の文字）を付ける。読み込み中は色の枠を表示する |

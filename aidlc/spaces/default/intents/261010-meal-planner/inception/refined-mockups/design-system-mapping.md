# デザインシステムの対応づけ

見た目の雰囲気は「あたたかい色で、やわらかい印象」[Q5 A]。部品は、既存の部品集を使うか自作するかを、技術の選定（次の段階）で決める [Q6 C]。ここでは、部品の種類と見た目の決まり（デザインの基準値）を定めます。

## 色

| 用途 | 色（目安） | 備考 |
|---|---|---|
| 背景 | クリーム色 `#FFF7ED` | 全画面の背景 |
| 文字（本文） | 濃い茶色 `#3B2A20` | 背景とのコントラスト比 4.5:1 以上 |
| 主ボタン・選択中 | 濃いオレンジ `#B45309` | 白文字を載せたときのコントラスト比 4.5:1 以上 |
| 副ボタンの枠線 | オレンジ `#B45309` | 背景は透明、文字は同じ色 |
| お気に入り | 赤みのオレンジ `#C2410C` | ♡／♥ |
| エラー | 濃い赤 `#B91C1C` | 文字とアイコンの両方で示す |
| 区切り線 | 薄い茶色 `#E7D5C5` | |

- 色は目安。実装のときに、実際のコントラスト比を計測して、足りなければ濃くする。
- 色だけで状態を伝えない。選択中・エラー・チェック済みには、必ず印（✓、アイコン、文字）を付ける。

## 文字

| 用途 | 大きさ | 太さ |
|---|---|---|
| 画面の名前 | 20px | 太字 |
| 料理名（カード） | 20px | 太字 |
| 本文 | 16px | ふつう |
| 補足（条件の表示、ラベル） | 14px | ふつう |

- 本文は 16px 未満にしない。文字の拡大（ブラウザの設定）に追随する。
- 行間は 1.5 倍を基本にする。

## 余白と形

- 余白の単位は 8px。画面の左右の余白は 16px。
- カードの角は丸め（12px）。影は薄く、浮いて見える程度。
- 押せる部分は 44px 以上。

## 部品の対応づけ

| 画面の部品 | 種類 | 用途の画面 |
|---|---|---|
| 下部タブ | ナビゲーション | 全画面 |
| 上部バー | ヘッダー | 全画面 |
| カード | 表示用の部品 | S3 |
| タイル（今日の気分） | 選択の部品（折り返して並べる、高さ 64px 以上） | S3c |
| チップ | 選択の部品 | S5、S4 |
| 画像（サムネ）と「AI が作ったイメージ」の印 | 表示用の部品 | S3、S5、S6 |
| 右下の「＋」ボタン | フローティングボタン（56px） | 主な画面 |
| カレンダー | 日付の表 | S9 |
| スワイプのカード | カード（左右に動かせる）。ボタンでも同じ操作 | S3 |
| 主ボタン／副ボタン／文字ボタン | ボタン | 全画面 |
| 入力欄（1 行、複数行） | フォーム | S1、S4、S6、S10 |
| 選択（ラジオ） | フォーム | S6（感想） |
| チェックボックス | フォーム | S7 |
| 下からのパネル | オーバーレイ | S6 |
| 確認ダイアログ | オーバーレイ | S6、S11 |
| 通知（トースト） | フィードバック | 全画面 |
| スケルトン | 読み込み中の表示 | S3、S5、S7、S9 |
| 空の状態の表示 | 文章とボタン | S3、S5、S7、S8、S9 |

## 方針

- 既存の部品集を使う場合も、上の色・文字・余白の基準を上書きして適用する。
- 部品集の選定は、技術の選定（次の段階）で行う。選ぶときの条件は次のとおり。
  - 上の部品がそろっている、または少ない手間で作れる。
  - キーボード操作とスクリーンリーダーに対応している。
  - スマートフォンの画面で動作が軽い。

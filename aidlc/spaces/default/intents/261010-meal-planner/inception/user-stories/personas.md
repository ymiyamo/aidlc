# ペルソナ

要件（`requirements.md`）と、ユーザーストーリーの計画への回答（Q1 A：2 種類）をもとにした利用者像です。

## P1 見つけて保存する人（優先度：1）

- **役割**：家族の食事を用意することが多い人。Instagram などの SNS を見ていて、偶然おいしそうな料理に出会う。
- **目標**：おいしそうなものを逃さずためておき、買い物前に見て「作ってみよう」と思いたい。
- **困りごと**：食事を準備すること全体が気が重い。献立を提案されるだけでは気持ちが動かない。
- **使う場面**：SNS を見ているとき（保存）と、買い物前（見る・選ぶ）。主にスマートフォン。

## P2 家族の一員（優先度：2）

- **役割**：P1 と同じ家族グループに入っている同居人。自分の好き嫌いを持つ。保存や記録も行う。
- **目標**：嫌いなものが出てこない。自分の好きなものも、候補に出てほしい。
- **困りごと**：好き嫌いを、そのたびに口で伝えるのが面倒。
- **使う場面**：自分の好き嫌いを登録するとき、保存された料理を見るとき、作った感想を記録するとき。

## ペルソナどうしの関係

- 同じ家族グループの中で、保存した料理、買い物リスト、献立、記録を共有する。
- P1 と P2 は別の人でも、同じ人でもよい（1 人のグループでも使える）。
